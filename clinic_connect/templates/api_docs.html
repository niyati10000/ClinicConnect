Getting Started

ClinicConnect operates as an API-first multi-tenant system. Authentication is session-based. All write endpoints validate security tokens (CSRF) and restrict queries to the authenticated clinic's database partition.

GET /api/stats

Fetch active summary metrics (patients count, available doctors count, today's appointments count).

Response Example (JSON)
{
  "patients": 6,
  "doctors": 5,
  "appointments": 3
}
GET /api/analytics-data

Retrieve detailed data models used to render Chart.js analytics graphs on the home dashboard.

Response Example (JSON)
{
  "registrations": {
    "labels": ["Jul 25", "Jul 26", "Jul 27"],
    "data": [2, 1, 3]
  },
  "workload": {
    "labels": ["Dr. Rajesh Kumar", "Dr. Priya Sharma"],
    "data": [4, 2]
  },
  "status": {
    "labels": ["Completed", "Scheduled"],
    "data": [2, 3]
  },
  "diagnoses": {
    "labels": ["Essential Hypertension", "Healthy pregnancy"],
    "data": [1, 1]
  }
}
GET /appointments/api/available-slots

Fetch 30-min scheduling slots for a specific doctor on a chosen date. Flags whether slot is available.

Query Parameters
  • `doctor_id` (Integer, Required)
  • `date` (String YYYY-MM-DD, Required)
Response Example (JSON)
{
  "slots": [
    { "time": "09:00 AM", "available": true },
    { "time": "09:30 AM", "available": false },
    { "time": "10:00 AM", "available": true }
  ]
}
POST /auth/switch-role

Switches active session role levels dynamically. Emulates access tokens mutations.

Request Payload (JSON)
{
  "role": "receptionist" | "doctor"
}
Response Example (JSON)
{
  "success": true,
  "role": "doctor"
}
POST /sync/execute

Flushes queued offline notifications to the simulated SMS gateway (only when Network Status = Online).

Response Example (JSON)
{
  "success": true,
  "synced_count": 1,
  "message": "Successfully synchronized 1 message(s)!"
}
